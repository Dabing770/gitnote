# Biologian muistiinpanot

Tämä repositorio sisältää biologian muistiinpanojani opiskelun tueksi. Muistiinpanot on järjestetty lukion biologian moduulien mukaan.

## Sisältö

- `BI/BI1` - Elämä ja evoluutio
- `BI/BI2-3` - Ekologia, ympäristö ja ihmisen vaikutukset
- `BI/BI4` - Solu ja perinnöllisyys
- `BI/BI5` - Ihmisen biologia
- `BI/BI6` - Biotekniikka ja sen sovellukset

## Huomio

Muistiinpanot ovat omia opiskelumuistiinpanojani, ja niitä päivitetään sekä täydennetään ajan myötä. Sisällössä voi olla keskeneräisiä kohtia tai virheitä.
