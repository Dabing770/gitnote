# gitnote学习笔记与网站-项目概览

- **项目位置**：`C:\gitnote`。
- **目标**：以 Markdown 笔记为内容源，建设可搜索、可导航并能通过 GitHub Pages 查看的网站，同时维护多 Obsidian vault 的 Git 规则。
- **已确认实现**：动态扫描 Markdown、路由、渲染、侧栏、搜索、主题、图片处理、静态导出、测试、lint、typecheck 和生产构建。
- **部署原则**：GitHub Pages 要验证实际托管的首页、笔记页、CSS、KaTeX 和图片资源，不能只验证本地构建。
- **Git 规则**：全局忽略 `**/.obsidian/`、`**/.trash/` 等配置／临时内容；保留 `.md`、图片和 PDF；批量添加前检查嵌套 `.git`。
- **资料子任务**：曾整理河南专升本公共英语与管理学 2020–2026 年真题 PDF，并记录来源、版本和校验结果。
- **验证边界**：项目主要工作已有成功记录，但当前线上状态可能变化，需要使用时重新核验。
