# PDF转Markdown工具-项目概览

- **相关位置**：`C:\Users\aojia\OneDrive\Dokumente\ChatGPT\trans`、`C:\Projects\2026\MinerU`（历史记录中的项目根位置需使用前复核）。
- **目标**：把 PDF 批量或通过简单界面转换为 Obsidian／GitHub 可用的 Markdown。
- **统一要求**：保留源 PDF；递归扫描；保留目录结构；默认跳过已有输出并提供 `--overwrite`；单文件失败不终止整批任务。
- **图片约定**：使用 `assets/...` 相对路径，并验证引用能够解析。

- **Windows 经验**：Windows ARM64 上重型依赖可能没有原生轮子；已有项目曾采用独立 x64 CPython 3.12 环境，避免替换系统 Python。
- **交付要求**：报告文件、转换策略、真实样例测试和已知限制；扫描件、公式、复杂表格和化学结构仍需人工复核。
