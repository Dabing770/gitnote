# 长期记忆知识库

本目录是大饼跨项目使用的长期记忆知识库（Obsidian 笔记库的一部分），用于沉淀重要决策、行为习惯、项目资料和沟通细节。所有内容仅来自本地文件（不接入外部聊天/邮件工具），由每日 02:00 的自动整理任务和每周复盘任务维护。

## 目录结构

- `00-收件箱/` —— **信息入口**。把当天的项目沟通记录、会议纪要、聊天记录导出、临时笔记等原始文件放进这里，即视为"授权"整理。每日任务只处理这个文件夹里新增/修改的文件（以及各项目 `04-沟通记录/*/原始素材/` 中尚未处理的文件）。
- `01-决策记录/` —— 重要决策，每个项目一个文件：`决策记录-{项目名}.md`。
- `02-习惯与偏好/` —— 大饼的行为习惯、工作偏好，跨项目通用，主文件 `大饼的工作习惯与偏好.md`。
- `03-项目资料/{项目名}/` —— 项目背景、范围、干系人、关键信息。主文件 `项目概览.md`。
- `04-沟通记录/{项目名}/` —— 按日期记录的沟通细节笔记（`YYYY-MM-DD.md`），子目录 `原始素材/` 存放处理后归档的原始文件。
- `05-归档/{项目名}/` —— 已结束项目的摘要 + 原始资料迁移至此。
- `索引.md` —— 全库地图（MOC），链接到各分类和各项目笔记。

## 分类规则（每日任务据此判断信息归属）

1. **决策记录**：出现明确结论/选择的内容（例如"决定采用……""以后统一……""确认……方案"）。写入格式：
   `## YYYY-MM-DD｜决策标题` + 背景、决策内容、原因（如有）、来源文件。
2. **习惯与偏好**：反复出现的行为模式、沟通风格、工作偏好（例如"我一般都……""不喜欢……""请以后……"）。写入 `02-习惯与偏好/大饼的工作习惯与偏好.md`，按主题分节，同主题内容合并更新而非重复追加。
3. **项目资料**：项目背景、范围、里程碑、干系人、链接等事实性信息。写入对应项目的 `项目概览.md`，采用"信息项 + 最后更新日期"的方式覆盖式更新，避免同一字段重复。
4. **沟通细节**：具体的对话/会议内容、待办事项、问题讨论。写入 `04-沟通记录/{项目名}/YYYY-MM-DD.md`，保留时间、参与方、要点、行动项。

不确定归属的内容，默认归入触发它的项目的 `沟通记录`，并在笔记开头加 `#待复核` 标签，留给每周复盘处理。

## 项目名判定

项目名从来源文件所在的项目文件夹名或文件内容中的项目名称推断。无法判定项目的内容放入 `03-项目资料/未分类/`。

## Wikilink 约定

笔记之间使用 `[[笔记名]]` 互链：沟通记录链接对应的项目概览和相关决策；决策记录链接来源沟通记录。每次新建项目笔记后，在 `索引.md` 对应分类下补一条链接。

## 每日任务（02:00）做什么

1. 扫描 `00-收件箱/` 及各项目 `原始素材/` 中的新文件。
2. 按上述规则提取信息，写入/更新对应笔记（同一事实避免重复写入，能合并则合并）。
3. 处理完的原始文件移动到对应项目 `04-沟通记录/{项目名}/原始素材/YYYY-MM-DD/`（保留原文，不删除）。
4. 在 `索引.md` 底部的"最近更新"追加一行处理摘要（日期 + 处理了哪些文件 + 新增/更新了哪些笔记）。

## 每周任务做什么

1. 复盘本周 `索引.md` 的"最近更新"记录和各分类笔记，合并重复或碎片化的内容。
2. 检查各项目状态：如果项目已连续较长时间无新沟通记录且此前信息显示已完成/收尾，征询判断是否已结束；对已结束项目，在 `05-归档/{项目名}/摘要.md` 写一份项目摘要（目标、结果、关键决策回顾、时间线），并将该项目 `03-项目资料/` 和 `04-沟通记录/` 下的原始资料整体移动到 `05-归档/{项目名}/原始资料/`。
3. 更新 `索引.md`，清理失效链接，把已归档项目移到索引的"已归档项目"分节。
