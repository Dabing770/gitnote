# Kemiallinen tasapaino – tasapainon häiritseminen (HI:n lisäys)

## Alkuperäinen tehtävä

Vetykaasu (H₂) ja jodikaasu (I₂) reagoivat muodostaen vetyjodidia (HI) seuraavan reaktion mukaisesti:

H₂(g) + I₂(g) ⇌ 2 HI(g)

Reaktion tasapainovakion arvo on K = 56,25 tietyssä lämpötilassa. Reaktioseos sisältää tällöin tasapainossa 0,40 mol vetykaasua, 0,40 mol jodikaasua ja 3,0 mol vetyjodidia. Reaktioastian tilavuus on 10,0 l. Tasapainossa olevaan reaktioseokseen lisätään 2,0 mol vetyjodidia.

a) Laske kunkin aineen konsentraatio vetyjodidin lisäyksen jälkeen.

## Ydinasiat

- Konsentraatio: **c = n / V**
- Kohdassa a) kysytään konsentraatiot **heti lisäyksen jälkeen**, ennen kuin tasapaino ehtii siirtyä. Ainemäärät otetaan siis suoraan: H₂ ja I₂ eivät muutu, HI:n ainemäärään lisätään 2,0 mol.
- Tilavuus (10,0 l) ei muutu lisäyksessä.
- Tarkistus: tasapainovakio
  K = c(HI)² / (c(H₂)·c(I₂)) = 0,30² / (0,040 · 0,040) = 56,25 ✔ (alkuperäisellä tasapainolla)
- Lisäyksen jälkeen reaktio-osamäärä Q = 0,50² / (0,040 · 0,040) = 156 > K, joten tasapaino siirtyy **vasemmalle** (HI hajoaa) – tätä tarvitaan vasta kohdassa b).

## Minun virheeni

Todennäköinen kompastuskivi: kohdassa a) yritetään heti laskea uusi tasapaino ja ratkaista muutosmuuttuja x, vaikka kysytään vain konsentraatiot **välittömästi lisäyksen jälkeen** (häirityssä, ei vielä tasapainoisessa tilassa). Toinen tyypillinen virhe on unohtaa jakaa ainemäärä tilavuudella eli antaa vastaus mooleina.

## Ratkaisu

V = 10,0 l

**Ainemäärät heti lisäyksen jälkeen**

- n(H₂) = 0,40 mol
- n(I₂) = 0,40 mol
- n(HI) = 3,0 mol + 2,0 mol = 5,0 mol

**Konsentraatiot** c = n / V:

- c(H₂) = 0,40 mol / 10,0 l = **0,040 mol/l**
- c(I₂) = 0,40 mol / 10,0 l = **0,040 mol/l**
- c(HI) = 5,0 mol / 10,0 l = **0,50 mol/l**

(Alkuperäisessä tasapainossa c(HI) oli 0,30 mol/l, mikä toteuttaa K = 56,25.)

## Mitä minun pitää osata

- Erottaa toisistaan **häiritty tila** (heti lisäyksen jälkeen) ja **uusi tasapainotila** – vasta jälkimmäinen vaatii ICE-taulukon ja K:n käyttöä.
- Laskea konsentraatio ainemäärästä ja tilavuudesta myös silloin, kun tehtävä antaa tiedot mooleina.
- Vertailla reaktio-osamäärää Q tasapainovakioon K ja päätellä siirtymissuunta: Q > K → vasemmalle, Q < K → oikealle.
- Kirjoittaa tasapainovakion lauseke kertoimet huomioiden: K = c(HI)² / (c(H₂)·c(I₂)).
